
# Toegangscontrole

De toegangscontrole hoort bij een bepaalde **Raadpleging** en query. Ze beschrijven hoe en waarop de controle plaatsvindt bij een Raadpleging. 

Voor een volledige beschrijving van de Raadpleeg usecase ga naar het hoofdstuk [Raadplegen](../raadplegen/index.md)

### CIZ
| Controle bij raadplegen van |  toegangscontrole |
| :-- |:-- | 
| Bij Indicatie betrokken zorgkantoren raadplegen |  [UCBR-0010-toegangscontrole](./UCBR-0010-toegangscontrole.md) | 
| Bij indicatie betrokken uitvoerende zorgkantoren raadplegen |  [UCBR-0011-toegangscontrole](./UCBR-0011-toegangscontrole.md) |
